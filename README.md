# 孵梦 HATCH

> 一个链接，不用装 App。记录梦境、用 AI 把碎片补全成场景、生成视频提示词，附带助眠音效。

**零依赖 · 单文件 · 纯前端** —— 整个产品就是一个 `index.html`，没有构建步骤、没有后端、没有账号。

---

## 为什么要做这个

人一生约三分之一时间在睡觉，其中约四分之一在做梦，但几乎没有产品认真对待「梦发生了什么」。绝大多数助眠软件只关心「睡得着、睡得久」，孵梦关心的是**睡着之后那段内容的记录与延展**：

- 醒来或半夜醒来，用 30 / 60 / 90 秒把梦的碎片录下来（越早记越全）；
- 白天用 AI（或本地规则）把零散描述还原成连贯场景，并追问感官细节帮你回忆；
- 把梦里的意象拿去联网查证、生成视频提示词，让它「动起来」；
- 需要入睡时，现场合成几种助眠音效陪你。

---

## 功能

| 模块 | 说明 |
|------|------|
| 记录 | 一键录音 + 实时转写，存到本地。暗色界面，半夜用不晃眼。 |
| 补全 | 选一条梦 → AI 还原场景 + 三个感官追问；可联网查现实原型、可生成视频提示词。不填 Key 时由本地意象引擎完成。 |
| 助眠 | 雨 / 海浪 / 风 / 白噪音 / 低频，全部 Web Audio 现场合成，可调音量、定时关。 |
| 记录本 | 所有梦本地留存，可回放录音、可删除。 |

## 技术栈

- **纯前端单文件**，无框架、无打包、无 CDN 引用
- 存储：`IndexedDB`（音频 Blob 直接存）
- 录音：`MediaRecorder` + `getUserMedia`
- 语音转写：`Web Speech API`（Chrome 系可用，失败自动降级为手填）
- 助眠音效：`Web Audio API` 现场合成噪声与振荡器
- AI 补全：浏览器直连 OpenAI 兼容接口（可选，Key 存本地）

## 本地运行

最简单 —— 直接用浏览器打开 `index.html`。

但**麦克风只在 HTTPS 或 localhost 下可用**，所以推荐：

```bash
# 在本仓库目录执行
python3 -m http.server 8099
# 浏览器打开 http://localhost:8099
```

要发给朋友在手机上用，需要公网 HTTPS。最简单的方式（临时）是用 cloudflared 之类把本地端口暴露成 https 链接。

> ⚠️ **微信内置浏览器禁用麦克风**。从微信点开请点右上角「··· → 在浏览器中打开」。

## 接入 AI（可选）

点开页面底部的「接一个 AI」：

- 接口地址：OpenAI 兼容的 `/chat/completions` 端点
- API Key：存在你这台手机 / 浏览器里，请求直接从本机发出
- 模型名：如 `gpt-4o-mini`

不填也能用 —— 补全会走内置的本地意象规则引擎。

> 提示：浏览器直连可能被对方服务器的跨域策略拦截；请使用支持 CORS 的端点。Key 直接存在本地，**不要填额度很大的 Key**。

---

## 隐私

- 所有梦只存在你自己的浏览器（`IndexedDB`），**没有账号、没有上传、没有服务器**。
- 换手机或清浏览器数据会丢，重要的梦请自行另存。
- AI 补全时，你写下的文字会发往你配置的接口。

---

## 已知限制

- 网页做不到「检测到睡着后注入」（锁屏后浏览器会掐掉声音），目前是「睡前陪伴式引导」。
- 锁屏后部分手机会静音，建议把自动锁屏调到最长。
- 端侧没有 ASR 模型，长段转写依赖浏览器自带能力。
- 视频目前只生成**提示词**，不代生成（避免替你烧钱）。
