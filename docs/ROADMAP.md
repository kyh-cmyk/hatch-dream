# 路线图 / 待认领

孵梦目前只是个 MVP，下面这些都没做或做得粗糙，欢迎认领。

## 记录与补全

- [ ] **导出 / 备份**：目前梦只存在 IndexedDB，换设备即丢。导出 JSON / 文本，最好能再导入。
- [ ] **AI 补全增强**：流式输出、接入更多模型、把「场景 + 追问」做成可迭代（答完一个追问再问下一个）。
- [ ] **本地规则引擎扩充**：现在意象词库只有 16 类，追加更多，并支持中英双语识别。
- [ ] **多语言**：界面与转写语言切换。

## 演绎

- [ ] **视频提示词对接**：目前只生成提示词，可接各家视频 API（用户自带 Key）一键生成。 `good first issue`
- [ ] **意象图鉴**：把反复出现的意象攒成网络，做可视化（之前设计稿里有，没实现）。

## 助眠

- [ ] **更多音效与混音**：叠加雨 + 风、添加环境脉冲等。 `good first issue`
- [ ] **渐隐 / 渐强曲线优化**：避免突然开始 / 停止。

## 工程

- [ ] **PWA**：离线可用 + 安装到主屏，体验更接近 App。 `good first issue`
- [ ] **入睡期注入的原生方案**：网页做不到「睡着后注入」，可考虑 PWA + 原生扩展，或提示用户用系统闹钟 + 定时播放。

## 不做什么

- 不做账号体系、不做云端存储（除非社区达成共识）。
- 不做「解梦」/「象征分析」—— 我们只帮人**回忆**，不替梦下定义。
- 不内置付费 Key。
